Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(100%);

Media Queries

Apply styles at different screen sizes.

@media (max-width: 600px)

Responsive Design

Design adjusts to different screens.

width: 100%;

Typography

Text adjusts to screen size.

font-size: clamp(1rem, 2vw, 2rem);
